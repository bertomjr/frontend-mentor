# Frontend Mentor

My implementations of [Frontend Mentor](https://www.frontendmentor.io/) challenges, built with HTML and CSS. I use these projects to practice translating designs into responsive interfaces and to strengthen my understanding of semantic HTML, accessibility, and CSS layout.

[Browse the projects](./newbie/) · [My Frontend Mentor profile](https://www.frontendmentor.io/profile/bertomjr) · [My GitHub profile](https://github.com/bertomjr)

## Projects

Challenges are organized by Frontend Mentor difficulty. My current projects are in the [`newbie/`](./newbie/) directory.

| Project | Difficulty | Learning focus |
| --- | --- | --- |
| QR code component | Newbie | Card layout, spacing, typography, and responsive sizing |
| Blog preview card | Newbie | Custom fonts, card composition, and interactive states |
| Social links profile | Newbie | Semantic links, reusable styles, and responsive layout |
| Recipe page | Newbie | Content structure, lists, tables, and responsive spacing |

## What I'm practicing

- Writing semantic HTML that gives content a clear structure.
- Building responsive layouts with CSS Grid, Flexbox, and media queries.
- Using custom properties to keep colors, spacing, and typography consistent.
- Considering keyboard navigation, focus visibility, and meaningful alternative text.
- Refining layouts across screen sizes while comparing them with the supplied designs.

These projects are part of my ongoing learning. I revisit earlier solutions as my understanding improves.

## View locally

Clone the repository:

```bash
git clone https://github.com/bertomjr/frontend-mentor.git
cd frontend-mentor
```

To serve the collection locally, run the following from the repository root if Python 3 is installed:

```bash
python3 -m http.server --bind 127.0.0.1 8000
```

Open [the local project directory](http://127.0.0.1:8000/newbie/), choose a challenge folder, and open its `index.html`. Stop the server with `Ctrl+C` when finished.
